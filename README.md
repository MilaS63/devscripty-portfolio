# DevScripty Portfolio

WordPress plugin that renders the portfolio grid for devscripty.org (staging build).

## What's inside
- `devscripty-portfolio.php`: plugin logic and portfolio items
- `assets/style.css`: grid and card styles
- `assets/script.js`: filtering and interactions

## Stack
WordPress, PHP, JavaScript, CSS
